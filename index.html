MANETTE

Stick : bouger (doucement = marche, à fond = trot) · RT : courir · A : passe · B : tir · X : tir à la hanche · Y : roucoulette · LT : saut (+ tir = tir en suspension) · LB / RB : changer · Start : pause
Appuie sur une touche ou un bouton pour le voir s'allumer. En 1 joueur, tu peux aussi jouer avec les flèches. Sur téléphone : joystick + boutons PASSE / TIR / SAUT / COURSE / CHG. Au clavier, Maj = courir. Avec la balle : 3 pas, puis dribble. Pause : Échap ou P.
